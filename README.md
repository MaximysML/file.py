# Discord Bot Relay

Консольный Python-клиент для общения **собственного бота** с выбранным ботом
в текстовом канале Discord. Поддерживает ручные запросы, отображение ответов,
префикс-инструкцию и ограниченную цепочку «продолжай».

## Запуск

Требуется Python 3.10+.

```sh
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python bot_relay.py
```

1. Создайте приложение и **бота** в Discord Developer Portal. В разделе Bot
   включите **Message Content Intent** и **Server Members Intent**.
2. Пригласите своего бота на сервер со scope `bot` и правами View Channel,
   Send Messages, Read Message History. Пригласите и целевого бота.
3. В Discord включите режим разработчика и скопируйте ID текстового канала.
4. При запуске введите токен (ввод скрыт), ID канала и ID или точное имя
   целевого бота. При совпадении имён используйте ID.
   Можно передать токен через переменную окружения `DISCORD_BOT_TOKEN`.
   Никогда не публикуйте токен и не используйте токен обычного аккаунта.

## Команды / встроенный промпт-справка

Команды вводятся **в консоли программы**, не в Discord. Они не регистрируются
как slash-команды Discord.

| Команда | Назначение |
| --- | --- |
| `/ask текст` или просто текст | Отправить запрос и показать один ответ |
| `/think текст` | Пометить публичные ответы «ДУМАЕТ» и автоматически продолжить |
| `/rounds N` | Число продолжений для `/think`: 0–10, по умолчанию 1 |
| `/continue текст` | Задать текст продолжения, по умолчанию «продолжай» |
| `/prompt текст` | Инструкция перед каждым новым запросом |
| `/prompt off` | Сбросить инструкцию |
| `/help` | Вывести справку |
| `/quit` | Завершить программу |

Пример:

```text
/prompt Отвечай по-русски. Продолжай рассказ только по запросу.
/rounds 2
/think Придумай начало истории про космос
/ask Как зовут главного героя?
/quit
```

## Ограничения

- Многие Discord-боты **игнорируют сообщения других ботов** либо принимают
  только slash-команды. Реле не обходит эти ограничения и не вызывает
  slash-команды от имени пользователя. Нужен бот с поддержкой текстовых
  запросов от ботов; одного его имени недостаточно для интеграции.
- `/think` — локальный режим, а не доступ к скрытым рассуждениям. Целевому
  боту отправляется текст после команды. Метка относится только к его
  опубликованному ответу. После него реле отправляет «продолжай».
- На каждый запрос берётся первое новое сообщение выбранного бота в канале.
  Вложения выводятся ссылками, embeds — текстом. Редактирования, потоковые
  обновления и ответы из нескольких сообщений не объединяются. Используйте
  отдельный тихий канал: чужой параллельный ответ может быть принят за ваш.
- Ответ выводится в консоль, не пересылается вторично в Discord. Между
  продолжениями пауза 2 секунды; через 90 секунд без ответа цепочка прекращается.
  Лимит Discord — 2000 символов вместе с упоминанием и инструкцией.
- Не запускайте встречные реле или рассылки. Работайте с разрешения владельца
  сервера. Ctrl+C завершает программу в том числе во время ожидания ответа;
  новые команды консоли принимаются после окончания текущей цепочки.

## Тесты

```sh
python -m unittest discover -s tests -v
```

Тесты проверяют локальную обработку команд, инструкций и ответов. Для проверки
сетевого обмена нужен реальный сервер, токен и совместимый целевой бот.
